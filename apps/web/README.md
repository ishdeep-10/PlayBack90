# PlayBack90 Web

Next.js frontend for the hosted PlayBack90 migration.

## Run locally

```bash
cd apps/web
npm install
NEXT_PUBLIC_API_BASE_URL=http://localhost:8000/api npm run dev
```

## Current phase-1 coverage

- landing page
- live scrape job submission
- league and season fixture browsing
- hosted Post Match Analysis shell
- placeholder routes for deferred pages
